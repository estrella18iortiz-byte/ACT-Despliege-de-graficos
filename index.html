Fundamentos Teóricos

La etiqueta <canvas> y el contexto 2D

El elemento <canvas> es una superficie de dibujo bitmap en HTML5. Para dibujar en él, se debe obtener su contexto de renderizado. El más común es '2d', que permite dibujar formas, textos e imágenes mediante una API de JavaScript.

  • getContext('2d'): Devuelve el objeto de contexto 2D.
  • Permite dibujar rectángulos (fillRect), círculos (arc), líneas y curvas Bézier.
  • Es fundamental para animaciones de alto rendimiento y gráficos generativos.

Fundamentos de p5.js

p5.js es una librería de JavaScript que hace que el dibujo en canvas sea accesible para artistas, diseñadores y principiantes. Se basa en los principios de Processing.

  • setup(): Se ejecuta una vez al inicio. Se usa para crear el lienzo (createCanvas()) y configuraciones iniciales.
  • draw(): Se ejecuta en bucle continuo (60 fps). Aquí se dibuja la escena y se actualizan las animaciones.
  • Simplifica la sintaxis: ellipse(x, y, ancho, alto) en lugar de ctx.arc().
