# Proyecto: Despliegue de Gráficos Interactivos

Sitio web desarrollado con HTML, CSS y JavaScript que muestra teoría y ejemplos prácticos sobre `<canvas>` y la librería **p5.js**.

## 🌐 Sitio en vivo

[https://estrella18iortiz-byte.github.io/ACT-Despliege-de-graficos/](https://estrella18iortiz-byte.github.io/ACT-Despliege-de-graficos/)

## 📌 Contenido del sitio

- **Teoría:** Explicación de la etiqueta `<canvas>` y sus contextos de renderizado 2D.
- **Teoría:** Fundamentos de la librería p5.js (`setup()`, `draw()`, `createCanvas()`).
- **Ejemplos con p5.js:** Dos dibujos creados con la librería (paisaje nocturno y animación interactiva).
- **Galería Khan Academy:** 5 proyectos originales con enlaces directos.
- **Inspector DOM:** Visualización gráfica del árbol jerárquico del DOM de las páginas del sitio.

## 🛠️ Tecnologías usadas

- HTML5
- CSS3
- JavaScript
- p5.js
- GitHub Pages
